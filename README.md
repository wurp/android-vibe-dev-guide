# Vibe Dev Guide

A step-by-step guide on your Android phone for starting a new app with [vibe-dev-template](https://github.com/wurp/vibe-dev-template). It shows one step per screen, opens each web page so closing it brings you back, and remembers where you left off.

## Install

On an Android phone, open this link in Chrome and install the file it downloads:
https://github.com/wurp/android-vibe-dev-guide/releases/download/test-build/app.apk

## Keep building

In the Claude app, open **Code** → **New session**, choose `android-vibe-dev-guide` above the message box, and describe what to change. (On a computer, [this link](https://claude.ai/code?repositories=wurp/android-vibe-dev-guide) opens it directly.)

Built with [vibe-dev-template](https://github.com/wurp/vibe-dev-template) and Claude.
